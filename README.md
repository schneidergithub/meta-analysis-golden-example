# Combining study results

A [meta-analysis](glossary.md#meta-analysis) exercise about combining results from three fictional studies.  Three fake schools are teaching the same course.  Each school has 100 students, and will be given the same exam at the end of 6 weeks. The experiment is to determine if students do better from rereading notes versus practice questions as preparation before the exam. 

| File | Purpose |
| --- | --- |
| [instruction.md](instruction.md) | The instructions for the task. |
| [studies.md](studies.md) | Three studies and the calculation card. |
| [glossary.md](glossary.md) | Explanations of terms used in the exercise. |
| [Worked answer](reference/golden.md) | The calculations and an example explanation of the results. |

The studies compare practice questions versus rereading notes.

The participant is the person or model completing this meta-analysis task. This exercise checks whether the participant can find the relevant numbers from the reported results of the experiment and follow the [calculation card](studies.md#calculation-card) to combine them. The worked answer shows the expected result of the meta-analysis.

Give the participant only `instruction.md`, `studies.md`, and `glossary.md`. Keep this overview and the worked answer out of the materials they can access. The repository itself does not enforce that separation yet.
